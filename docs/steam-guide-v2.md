# Steam 教学系统 V2

当前策略：教学负责说明稳定 UI 与玩法入口；真实资源条件由玩法系统负责，教学不绑定具体库存物品。

## 公共修复

- 修复 GuideOverlay 完成写回竞态。
- press 步骤使用 capture + composedPath，在业务按钮切换视图前记录教学推进。
- 当前页面运行期使用 sessionStorage 恢复 cursor，防止组件意外重挂回到第 0 步。
- “先不看”清理 cursor，下次从头，避免业务页面状态与教学 cursor 错位。
- look 高亮区域本身可点击推进。
- 锚点暂时不存在时不再锁死整个页面。
- 完成后清理教学缓存与 guide/guideStep 参数。

## 第一件法兵

教学只依赖稳定 UI：

地火器炉 → 道装图录 → 进入地火器炉 → 认识开炉位置

教学不再要求：

- 指定炼气法兵图纸；
- 指定材料位；
- 指定“青石”；
- 指定确认开炉按钮。

原因：这些对象受玩家真实库存影响。图纸或材料可能已被消耗、出售、转移，历史角色也可能没有对应奖励。教程不能因为缺少某个物品而死锁。

主线仍由原剧情条件同时验收：

`guide:forge-first-weapon + weapon_forged`

因此玩家没有合格材料时可以先离开去获取材料，之后回来真正铸成法兵。

炼器实际接受符合当前图纸品阶要求的 `ore / tcdb / aux / monster`，并不只接受青石。

## 第一炉炼丹

仍保持“认炉教学”，不强制修改为 mode=all。当前随心炼制还需要心念、费用与灵气检查，现有教学没有安全覆盖这些输入；本版仅修正文案。
